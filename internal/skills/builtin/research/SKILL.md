# Deep Research

Plan → search → analyze → synthesize.

## When to use
- "Research X in depth"
- "Write a report on Y"

## Steps
1. Confirm depth/format with the user
2. Decompose topic into steps
3. Search multiple engines
4. Analyze per step
5. Synthesize report
6. Save as `vfs://note/<id>`
